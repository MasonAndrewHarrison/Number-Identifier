
## Setup
1. Clone this repository: `git clone https://github.com/MasonAndrewHarrison/Number-Identifier.git`
3. Create virtual environment: `python -m venv venv`
4. Activate it:
   (Linux)`source venv/bin/activate`\
   (Windows)`source venv/bin/activate`\
6. For GPU Compute(Optional): `pip install torch==2.8.0 torchvision==0.23.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu121`
7. Install dependencies: `pip install -r requirements.txt`
8. Run: `python main.py`
